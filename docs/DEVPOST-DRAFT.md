# Devpost submission materials

## Project description

Friction turns AI assistance into a learning progression. Teachers upload a syllabus to create a skill tree. A Chrome extension connects students' Claude conversations to that tree and adjusts the help they receive as they demonstrate understanding. Teachers and students see progress update live, and students can use a limited Bypass when they need direct help.

Claude supports syllabus parsing, topic classification and answer evaluation. When configured, Moss retrieves candidate course concepts for prompts without a keyword match; Claude makes the final classification. Retrieval does not award mastery. Do not claim a measured accuracy improvement from Moss.
