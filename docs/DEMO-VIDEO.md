Before recording: close private tabs, hide keys/terminal environment values, use fresh dedicated demo data, confirm API/student/dashboard match and reload the built extension and Claude. Run two timed rehearsals. Model timing varies; label edits around loading time. Do not promise a gold card after one answer in normal mode. If showing Moss, capture actual retrieval evidence, not just a keyword match or configured credentials.

Record the screen and narration with OBS, your OS recorder or an equivalent tool. Export a roughly three-minute MP4, play it back with audio, and save a backup. Upload it to a video host allowed by the official submission rules; test the viewing link in a signed-out browser. Add the real viewing URL near the top of README and in Devpost. Check the official video length/format requirements before submitting.
